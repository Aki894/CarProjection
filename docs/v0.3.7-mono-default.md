# v0.3.7：默认 48 kHz 单声道

根据用户对 2020 款中国版 Lexus ES200 的实车反馈，16、24、32、44.1、48 kHz 均可播放，选择双声道仍听到单声道。该结果不代表其他车机支持这些规格，也未确认其内部解码或重采样方式。

- 默认 TTS 输出为 48 kHz、单声道、PCM16；48 kHz 输入左右声道混合为单声道。
- 移除声道选择，固定单声道。保留采样率下拉菜单：16、24、32、44.1、48 kHz。
- 首次升级自动迁移为 48 kHz 单声道；此后保留用户选择的备选采样率，重启不会覆盖。
- 切换立即重启 TTS 音频会话。当前采样率测试音、固定 16 kHz 基线测试音、输出音量调节和日志导出继续可用。

如遇无声、卡顿或异常，先切换较低采样率（例如 16 kHz），必要时重连 USB。更高的传输采样率不保证车机最终输出更高音质。

验证：运行 tools/check-audio.sh，并通过 GitHub Actions 构建 APK。实车复测重点为升级默认值、切换采样率及重启后的选择记忆。
