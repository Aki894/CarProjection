# v0.3.5：车机输出音量

versionCode 17，保留此前 TTS、反控、双 tap 和日志功能。

## 调节

音频设置新增「车机输出音量」，范围 0～100%，没有已保存设置时默认 30%。无需重连：播放过程中调整即可，设置自动保存。

- 100%：此前没有软件衰减时的原始输出，不额外放大。
- 30%：PCM 振幅乘以 0.3，约 -10.5 dB；滑块百分比表示振幅比例，不是主观响度百分比。
- 0%：输出静音；捕获和 TTS 会话仍继续，恢复音量不需要重新 INIT。

增益用于 TTS/MEDIA 的实时 PCM 数据与测试音，不修改 protobuf INIT/END、输入捕获缓冲区或手机系统音量。目标改变时，使用一个音频包长度的平滑过渡。诊断日志和导出头部会记录所选音量，RMS/peak 仍表示音量处理前的捕获数据。

## 手机同步出声

AudioPlaybackCapture 复制播放音频，并不将第三方应用音频独占路由到车机。这版的车机输出滑块不会改变手机扬声器音量。

可手动将手机媒体音量调到 0，确认车机仍有声音；若车机也静音，将手机音量恢复，再查看捕获 RMS/peak。不同手机和播放器是否在系统静音后仍提供捕获数据，需要实际确认，本版不自动修改手机音量。

## 车机设置

Lexus 官方对于导航提示音给出的路径是 Setup → Voice → Voice Volume：
https://support.lexus.com/s/article/How-do-I-change-my-Na-10479

这不是对中国版 2020 ES200 CarLife TTS 路由的验证。应用内软件衰减直接作用于发出的 PCM，不依赖车机是否开放该音量设置。

## 验证

在车机播放音乐时，依次尝试 30%、10%、0%、再回到 30%。确认实时变小、静音和恢复；再测试 TTS 测试音。100% 等于旧版原始输出，目前用户已反馈音量较大，可按需要选择较低比例。

JDK 检查：0% 静音、100% 字节一致、正负满量程衰减、双声道共同增益与平滑过渡、范围限制、输入缓冲区不被改写。实际响度、音量滑块手感及手机静音后的捕获行为仍需设备测试。
