# v0.3.3：稳定性改进与实车测试清单

versionCode 15，可覆盖安装使用固定 debug 签名的旧版。保留 v0.3.2 的 TTS 兼容模式与原设置。

## 本版完善

- USB 外层头和消息体支持多次读取，不再依赖一次 read 返回完整消息。对截断、非法长度和无符号内层长度进行处理。
- 重连为每次 USB 连接分配代次，并固定当前读写流；旧读写流报错不会重置新连接。重新打开配件前先停止旧会话。
- 页面销毁时停止投屏、释放后台线程并关闭 USB 描述符，避免持有旧 Activity。
- 视频输出缓冲区的空数据分支只在 finally 中释放一次。
- 测试音在断开、销毁、停止投屏或切换音频模式时中断，不必继续播满两秒；防止快速连点排入多个测试。
- 修复多线程共用 SimpleDateFormat 的日志时间戳风险，并在主线程安排日志界面更新。
- 新增「导出诊断日志」：用 Android 文件选择器保存 UTF-8 文本，不需要额外存储权限。导出不受「仅输入日志」过滤限制。
- 显示最近 300 行；导出保存最近 5000 行，并合并最近 1000 条关键音频/握手/亮度诊断，按实际产生顺序去重。日志仍为内存环形缓存，不是永久后台录制；进程退出前应导出。

## 明天建议按此顺序测试

1. **启动与重连**：安装 v0.3.3、连接投屏，拔插 USB 两三次。观察是否有黑屏、停在 loading 或旧错误导致新连接退出。
2. **TTS 测试音**：开启 TTS 兼容模式、拔插 USB，点 16 kHz 测试音。确认有声、结束后能恢复捕获。试一次快速连点，以及测试音中拔掉 USB 后重新连接。
3. **BGM 捕获与持续播放**：播放音乐 5～10 分钟，检查 RMS/peak、sent/queued/dropped、断音、爆音和声音延迟。测试音有声但 PCM 静音时，应先排查源播放器的捕获限制。
4. **导航与 BGM**：同时播放，确认导航提示音是否进入捕获。普通 AudioPlaybackCapture 的限制仍在，不能保证每种导航应用都支持。
5. **停止投屏**：从系统通知停止，检查声音停止和亮度恢复。拔插 USB 后能再次启动。
6. **反向控制回归**：移动光标、机械 OK、BACK、双 tap + 滑动，以及打开「拖拽时锁定指针位置」后的连续滚动。
7. **自动变暗**：开启功能与所需权限，等待设定时间变暗；触摸手机应恢复，车机操作应保持暗屏；停止投屏或断开 USB 后恢复原亮度与亮度模式。OEM 实际表现尚需验证。
8. **日志导出**：停止测试后立即展开日志、点「导出诊断日志」，选择保存位置，再将 txt 发回来。即使界面开启「仅输入日志」，文件仍包含音频诊断。

## 今晚可验证与仍待验证的边界

JDK 检查覆盖分段读取、EOF、零长度读取、非法帧长度、日志保留与并发时间戳，以及重采样的音质与计数检查；GitHub Actions 验证 Android 编译和固定签名 APK 生成。

实车音频路由、TTS 连续播放超时、手机实际捕获权限、OEM 亮度行为、反向手势与重连稳定性，均需要明天的设备测试。高采样率 TTS、蓝牙握手补全和专用导航音频捕获暂不加入本版。
